# Лабораторная работа 3, вариант 6 (Python)

**Вариант 6** = строка «Глобальная пороговая обработка (2 метода) + Адаптивная пороговая обработка»
и столбец «Поэлементные операции + линейное контрастирование».

## Запуск
```
pip install -r requirements.txt
streamlit run app.py
```
Если Streamlit спрашивает email — нажмите Enter. Приложение откроется на http://localhost:8501.

## Публикация («веб-приложение в общем доступе»)
1. Загрузите папку на GitHub (файлы `app.py`, `*.py`, `report.md`, `requirements.txt`, папка `images/`).
2. На https://share.streamlit.io создайте приложение из репозитория, главный файл — `app.py`.
3. Отправьте преподавателю полученную ссылку, исходный код и этот README.

## Структура
| Файл | Назначение |
|---|---|
| `app.py` | интерфейс (3 раздела: пороги, поэлементные операции и контраст, пояснения) |
| `thresholding.py` | Оцу, итеративный, адаптивные методы (блоки; локальные статистики), интегральное изображение |
| `pointwise.py` | поэлементные операции, линейное контрастирование |
| `histogram.py` | гистограммы (одна; пара «до / после») |
| `test_images.py` | генератор базы изображений (`python test_images.py` сохраняет в `images/`) |
| `report.md` | пояснения и анализ (показывается в разделе «Пояснения») |
| `images/` | сохранённая база изображений (PNG) |

## Что нужно уточнить
Адаптивный алгоритм «из лекции» в задании не описан, поэтому реализованы два классических варианта.
Если в лекции другой, замените функцию в `thresholding.py` и поправьте `report.md`.
